# 让每段路都算数

在十余种工作与业务场景里辨认可迁移能力，把看似分散的经历连成自己的路——让走过的每一段都成为下一步的底气。

**做过好几段实习，但内容东一块西一块，不知道下一段该继续试，还是赶紧选一个方向深挖？**

把你的**实习经历、简历，或者正在纠结的目标岗位/JD**丢进来。这个 Skill 会帮你一段段拆开看：你真正做过什么、留下了什么结果，哪些能力下一份工作还能继续用；再帮你判断这些经历到底能不能串成一条线，下一段更适合继续垂直、低成本换个方向试试，还是先别急着跳。

如果你卡在面试表达，也可以直接问：**“我这几段实习这么杂，面试官问职业规划时到底怎么讲？”**

**关于 @小挞要上岸（沉淀版）**

她自己走过的就是一条很不“标准”的路径。公开内容里，她提到过**十余种不同工作/业务场景**，包括销售、地推、客服、工厂、家教、直播、PR，以及后来的品牌种草、新媒体、内容、达人/创作者/商家、策略运营等；秋招时，她还曾针对 **5–6 类不同目标岗位**分别调整简历和自我介绍。她也公开写过跨岗求职、岗位拆解、经历复盘，以及**零游戏实习转投游戏运营**时遇到的真实面试追问。这个 Skill 会把这些真实经历和方法当作参考，但不会把她的路径硬套到你身上。

**怎么用**

- **在 AI 工具里用：**复制这个 Skill 的链接，粘贴到 Codex 等支持 Skill 的 AI 工具中，再把你的简历、经历或目标 JD 发进去开始聊。
- **在 Tara 里用：**直接进入这个 Skill 对话，把你的具体情况告诉 Tara；如果最后还想听小挞本人怎么判断，也可以继续从 Skill 找到她聊。

Skill 沿用 `ishann-tara-ai-career` 的咨询式对话结构：一次只问一个必要问题，边问边给小判断，并在信息达到最低阈值后给出经历拆解、可迁移能力、隐藏主线、下一步选择和面试表达。

## 使用方式

可直接从以下问题开始：

- “我做过三段不同方向的实习，怎么判断有没有主线？”
- “下一段应该继续垂直，还是再探索一次？”
- “面试时怎么解释我一直换方向？”

## 证据边界

所有蛋挞相关事实只能来自 `references/creator-evidence.md` 已核验的材料。当前版本盘点主页 33 篇笔记、复核 20 篇正文，最终纳入 13 篇相关 Context。标题、岗位名或常识不能作为事实补全依据；材料不支持的内容必须省略或转交本人回答。
