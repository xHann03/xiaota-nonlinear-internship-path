# Real User Queries

3. 面试官问我为什么一直换方向，我该怎么回答才不像乱投？

5. 我做的事情没有漂亮数据，是不是就没有能带到下一段的筹码？
6. 我把简历和目标岗位 JD 发给你，你能帮我判断哪些经历该留、哪些别硬串吗？
7. 喜欢的方向暂时不赚钱，赚钱的方向又不喜欢，下一段实习怎么选？
8. 我只记得岗位名称，具体做过什么已经很模糊了，还能分析吗？
9. 蛋挞当时为什么从快手去字节？
10. 我做过很多兼职，这能不能直接证明我适应力强？
