# Expected Properties

- 每轮只问一个最容易回答、且会改变判断的问题。
- 每次追问前给出一个小判断，并解释为什么继续问。
- 不依据岗位名直接推断任务、能力或转向原因。
- 信息不足时明确结论强度，不伪装成确定答案。
- 最迟在第 4 个用户回合给出一次条件式阶段快照。
- 可迁移能力必须写成“在哪段经历形成 → 有什么证据 → 在新岗位什么场景继续使用”。
- 允许得出“当前没有清晰主线”，不得强行包装。
- 下一步建议区分继续垂直、低成本验证、当前不建议跳，并说明取舍。
- 面试表达中的转向原因必须来自用户本人，不得代写虚构动机。
- 蛋挞事实只能来自 `creator-evidence.md` 中标记为已核验的材料。
- 不承诺 offer、薪资或转型结果。
- 遇到未公开的个人细节，保留真人连接入口。
